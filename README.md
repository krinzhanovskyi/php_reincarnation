# PHP Exercises

A collection of standalone PHP command-line exercises for practicing programming fundamentals. Prompts and output are mostly in German; some scripts ask for input interactively.

## Contents

- `12_11_2026/` — 31 numbered exercises
- `12_11_2026/auftraege/` — longer assignments

### Assignments

- `auftraege/auftrag_1.php` — interactive arithmetic quiz covering addition, subtraction, multiplication, and division, with a score at the end.

The exercises cover variables, strings, console input and output, arithmetic, conditions, functions, loops, arrays, and menu-based programs.

## Requirements

Install PHP CLI. Run interactive exercises in a terminal.

## Run an exercise

From the project root, run an individual script:

```powershell
php .\12_11_2026\aufgabe_3.php
php .\12_11_2026\auftraege\auftrag_1.php
```

Replace the filename with any exercise you want to run. Each PHP file is standalone; no Composer setup is required.
