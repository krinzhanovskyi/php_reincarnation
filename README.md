# PHP Beginner Exercises

A collection of small, standalone PHP command-line exercises for practicing programming fundamentals. The exercises use German prompts and output.

## Topics

- Variables, strings, functions, and output
- Reading input from the command line
- Basic arithmetic and calculations
- Conditions and comparisons
- `switch` statements and simple menu choices

## Run an exercise

Install PHP CLI, then run an individual file from the project root:

```bash
php 12_11_2026/aufgabe_3.php
```

or

```bash
cd /12_11_2026
php aufgabe_3.php
```

Replace `aufgabe_3.php` with the exercise you want to try. The files are independent and can be run separately.
